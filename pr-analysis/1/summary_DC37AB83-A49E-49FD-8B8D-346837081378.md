## Focus check 2: no external script loads or trackers — PASS, one caveat

- Exactly one `<script>` tag, inline, no `src` (`review-screen.html:290`).
- `grep -nE '<script|src=|fetch\(|XMLHttpRequest|import\(|sendBeacon|WebSocket|EventSource|navigator\.|\.src'`
  over the file matches only line 290 — no remote scripts, no beacons, no telemetry.
- `grep -nE 'https?://'` matches only lines 3, 4 (Google Fonts) and 6 (inert URL
  inside the header comment).
- Caveat (posted as P3): lines 3–4 preconnect to and load a stylesheet from
  `fonts.googleapis.com`, which also pulls font binaries from `fonts.gstatic.com`.
  This is neither a script nor a tracker, and the sibling README discloses it
  (`prototypes/README.md:8` — "no dependencies besides Google Fonts"), so it is
  deliberate. But it is the file's only network fetch: every future reader who opens
  this permanently-archived doc sends a request to Google (IP + UA). Font stacks
  already carry system fallbacks (`review-screen.html:46-48`), so dropping lines 3–4
  degrades only to system fonts. `grep -rln 'fonts.googleapis' docs/` shows this is
  the only prototype doing it (the other hit is an unrelated mintlify-migration tmp
  stylesheet).
