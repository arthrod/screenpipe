## How it fits the PR

These 16 lines are the typed seam between the shared Workflows UI and the new Automation
Flows feature:

- The Task Page consumes the capability flags in `packages/workflows-ui/src/workflows-app.tsx`:
  `createsFlow` gate at `workflows-app.tsx:728` (requires `createAutomationFlow` present, a
  truthy `workflow.id`, and `canCreateAutomationFlow?.(id) ?? true`), the header
  "Open automation" button at `:740` (only when `findAutomationFlow` AND
  `openAutomationFlow` are present), and `createFlow`/`findFlow` props at `:760-761`.
- `WorkflowQuestions` implements the creation semantics in
  `packages/workflows-ui/src/workflow-questions.tsx`: with `createFlow` present every
  Clarification Question becomes required (EXTRA excluded, `:122-123`; `complete` at `:236`;
  gate at `:261`), answers are persisted before creation so the Flow is never built from
  unsaved answers (`:265-267`), and only answered fields are sent (`:267`).
- The desktop host implements all four members in
  `apps/screenpipe-app-tauri/lib/workflows/automation-flows.ts:38-91`: an engine-side
  allowlist of creatable task ids (`:38`), create-then-open-Review-Screen (`:43-52`), a
  per-device localStorage task→Flow map re-checked against the engine (`:57-89`), and
  `openAutomationFlow` (`:91`), wired in `apps/screenpipe-app-tauri/lib/workflows/desktop-platform.ts:163-166`.
- `openQuestionChoices` is consumed at `workflow-questions.tsx:298-299` (choice buttons
  above the textarea). Its only producer is the demo task fixture
  `apps/screenpipe-app-tauri/lib/automation-flows/demo-task/detected-task.ts:50-53,202-203`;
  there is **no Rust/engine producer** (rg over `crates/` finds `openQuestions` handling at
  `crates/screenpipe-core/src/workflows/mod.rs:674-696` but no choices). So the field is
  demo-only today — intentional for this PR's demo focus, and harmless: it's optional, old
  persisted catalogs (`schemaVersion: 5`, `model.ts:248`) simply lack the key, and the
  consumer reads it defensively (`?.[question] ?? []`, `workflow-questions.tsx:298`).
