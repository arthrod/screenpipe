# Issue tracker: local markdown

Tickets are markdown files under `.scratch/<topic>/`, one file per ticket. Add a
`Status:` line if useful. Plans live next to them. No other structure is
required.

## Skill compatibility

When a skill says "publish to the issue tracker", create a file under
`.scratch/<topic>/`. When it says "fetch the relevant ticket", read the path or
number the user gives.
