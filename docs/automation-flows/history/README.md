# Automation Flows: design history

These folders record how Automation Flows were designed and built during a
two-day hackathon. They are history, not current rules: specs, decisions,
tickets, the demo runbook and handoff notes, kept as they were written.

- `hackathon/`: the first round (spec with decisions D1…, tickets 01–27,
  demo runbook, handoffs, live evidence).
- `flows-round-two/`: the second round (tickets 01–16 and the
  feature-to-test coverage table).

Some of this material describes a scripted demo (a pre-built task and
workflow). For what the feature does today and the design rules that apply,
read the root `README.md`.
